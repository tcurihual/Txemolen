# Txemolen

Txemolen es un sistema para ayudar a cualquier persona que requiera de un sistema para registrar sus calorias,
este cuenta con una gran cantidad de alimentos obtenidos de:

- [Open Food Facts](https://world.openfoodfacts.org/)

### Stack:

Frontend:

- React + Typescript

Backend:

- Rust + Axum

Database

- PostgreSQL

### Instalación 
    Clona el proyecto con git clone
    
Es necesario generar dos terminales para levantar tanto el backend como frontend

    cd backend
    cd frontend
Luego ejecutar en el backend 

    cargo run
y en el front

    pnpm install
    pnpm run dev

Para la instalación de rust, node y postgreSQL verificar sus debidos procesos en sus paginas
- rust: https://www.rust-lang.org/learn/get-started
- node: https://nodejs.org/en/download
- postgresql: https://www.postgresql.org/download/
